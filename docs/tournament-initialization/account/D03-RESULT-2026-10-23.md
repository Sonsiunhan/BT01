## 1. Tóm tắt các hạng mục đã hoàn thành

### 1.1. Hợp đồng dữ liệu (`packages/contracts/src/roster/d03.dto.ts`)
- Định nghĩa schema Zod và TypeScript types chuẩn cho việc parse & preview danh sách:
  - `RosterRowSchema`: Các trường thông tin thí sinh bắt buộc (`unit_code`, `student_or_member_id`, `full_name`, `username`, `email`).
  - `RosterPreviewRowSchema`: Cấu trúc dòng xem trước (`rowNumber`, `data`, `person_key`, `valid`, `errors`, `warnings`).
  - `RosterPreviewRequestSchema`: Yêu cầu gửi tệp kèm Base64 (`fileName`, `fileContent`, `allowedUnits`, `maxRows`).
  - `RosterPreviewResponseSchema`: Tổng hợp dòng hợp lệ, dòng lỗi, dòng cảnh báo, sức chứa đợt (`batchCapacity`, `totalRows`, `validRows`, `errorRows`, `warningRows`, `rows`).

### 1.2. Backend API & Dịch vụ (`apps/server/src/modules/roster/`)
- **Định tuyến HTTP (`roster.route.ts`):**
  - `POST /admin/roster/preview`: Xác thực quyền `SYSTEM_ADMIN` hoặc `TOURNAMENT_ADMIN`.
  - Hỗ trợ giải mã tệp an toàn (Buffer decode từ UTF-8 hoặc Base64).
  - Giới hạn kích thước tệp upload `bodyLimit` theo cấu hình `rosterImportMaxBytes` (2MB).
- **Dịch vụ Roster (`roster.service.ts`):**
  - `previewRoster()`: Hỗ trợ tệp định dạng CSV và XLSX.
  - Tự động sinh `person_key` chuẩn: `${unit_code}:${student_or_member_id}`.
  - Kiểm tra tính duy nhất trong tệp: Phát hiện trùng lặp `person_key`, `username`, `full_name`, `email`.
  - Kiểm tra phạm vi đơn vị (`unit_code` thuộc `allowedUnits` của hợp đồng).
  - Hoạt động chỉ đọc (read-only), không tạo dữ liệu lưu trữ khi chỉ xem trước.

### 1.3. Giao diện người dùng Frontend (`apps/web/src/features/tournament-roster/`)
- **Trang Roster (`TournamentRosterPage.tsx` — Page P10):**
  - Giao diện tải tệp CSV/XLSX với hỗ trợ chọn tệp kéo thả.
  - Nút "Xem trước (Preview)" gọi API `/admin/roster/preview`.
  - Khối tóm tắt thông số trực quan: Tổng số dòng, Hợp lệ, Lỗi, Cảnh báo.
  - Bảng xem trước chi tiết (Preview Table) với phân biệt màu sắc dòng hợp lệ (xanh) và dòng lỗi (đỏ), hiển thị danh sách lỗi rõ ràng.
- **Client API (`tournamentRosterApi.ts`):**
