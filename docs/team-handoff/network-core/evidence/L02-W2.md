## Compatibility & Projection Table (Bàn giao Đức & Nam & Sơn)

### 1. Compatibility Matrix giữa 0.1 và 0.2

| Thành phần | Protocol 0.1 | Protocol 0.2 | Quy tắc chuyển đổi / Bảo vệ |
|---|---|---|---|
| `protocolVersion` | `"0.1"` | `"0.2"` | Client 0.1 gửi query `protocolVersion=0.1` hoặc omitted; server không gửi payload 0.2 thô cho client 0.1 |
| Thời gian (wire) | ISO String hoặc number hỗn hợp | UTC epoch ms (`number`) | Adapter chuyển đổi timestamp ISO cũ sang epoch ms |
| Snapshot Live | Chứa toàn bộ `moves` & `publicTimeline` | `CompactMatchSnapshot`: chỉ chứa board 81 ô, clocks, status; moves tách riêng | Adapter V2→V1 gán default `playMode: MANUAL`, `timerSeconds: 30`, `moves: []` |
| Bàn cờ & Luật | Mặc định 9 quân/bên (18 quân), v1 | 18 quân/bên (36 quân), `rps-v2` kèm seed và version | V1 đọc được bàn cờ V2 qua adapter; không tự gán default MANUAL/BLUE |
| Lỗi kết thúc | `EXTINCTION`, `GOAL_REACHED`, `TIMEOUT`, v.v. | Bổ sung `NO_LEGAL_MOVES` | UI và adapter hiển thị "Bị khóa nước đi." |

### 2. Visibility Whitelist & Anti-Leak Rules

| Cấp độ chiếu (Projection) | Trường được phép | Trường bị chặn tuyệt đối |
|---|---|---|
| **Public Live / SSE / Spectator / Replay** | `matchId`, `roomId`, `mode`, `status`, `players` (userId, username, displayName, side, ready, connected), `board` (81 ô), `pieceCounts`, `currentTurn`, `winner`, `resultReason`, `clocksMs`, `runningSide`, `serverTime`, `sequence`, `stateVersion`, lifecycle timestamps (`pausedAt`, v.v.) | Source Python, memory, private logs, invocation seed/token, internal stacks, secrets |
