# OTT v2 audio attribution

The `lobby_loop.wav` and `match_loop.wav` tracks are original procedural
synthwave loops generated for this project by `scripts/generate-bgm.mjs`.

- Title: `Lobby Loop` / `Match Loop`
- Author: OTT v2 project (original procedural composition)
- Source URL: this repository (`scripts/generate-bgm.mjs`)
- License: CC0-style dedication for this project; no third-party samples or recordings are used.

The browser loads these tracks only after the first user gesture, and BGM is OFF
by default. Each track is intentionally small and remains below the 5 MB budget.
